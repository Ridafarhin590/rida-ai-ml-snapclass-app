# ai-attendance-project-app# 🎓 AI Attendance System

## 📌 Overview
This project is an AI-based Attendance Management System using:
- Face Recognition
- Voice Analysis (optional)
- Supabase Database
- Streamlit UI

## 🚀 Features
- Face-based login
- Voice-based attendance
- Subject management
- Attendance tracking
- Notes & Notices system
- Student messaging (with privacy control)

## 🛠️ Tech Stack
- Python 3.10
- Streamlit
- OpenCV
- Supabase
- NumPy / Pandas

## ⚙️ Setup

```bash
pip install -r requirements.txt
python -m streamlit run app.py
